1. 電流の発熱作用・ジュール熱・比熱（p.48〜49）

  • 抵抗をもつ導体に電流を流すと発生する熱を ジュール熱 といい、この関係を証明した法則を ジュールの法則 という。
  • ジュール熱の公式：Q = I²Rt = VIt = (V²/R)t [J]（時間 t は必ず 秒 [s] で計算する）。
  • 物質の温度を 1℃ 上昇させるのに必要な熱を 熱容量 といい、物質 1kg あたりの熱容量を 比熱 という。
  • 熱量の式：Q = Mc(T₂ - T₁) [J]。水の比熱は 4.19 × 10³ J/(kg・K)。
  • セルシウス温度 t [℃] と絶対温度 T [K] の換算：T = t + 273.15。また、1 cal = 4.19 J。

2. 電力と電力量（p.50〜51）

  • 単位時間あたりの電気エネルギーを 電力 といい、単位には ワット [W]（1W = 1J/s）を用いる。
  • 電力の公式：P = Q/t = I²R = VI = V²/R [W]。
  • 電気エネルギーがある時間に行った仕事を 電力量 といい、式 W = Pt [J] で表される。
  • 電力量の単位換算：1 W・h = 3600 J、1 kW・h = 3.6 × 10⁶ J。
  • 近年普及している通信機能つきの電子式電力量計を スマートメーター という。

3. 温度上昇と許容電流（p.52〜53）

  • 絶縁物が支障なく使える限界の温度を 最高使用温度 といい、基準となる周囲温度を 最高周囲温度（JISで 40℃）という。
  • 耐熱クラス105（A）の場合、許される最大の温度上昇（温度上昇限度）は 105 - 40 = 65℃ である。
  • 耐熱クラス（JIS C 4003）：Y(90℃), A(105℃), E(120℃), B(130℃), F(155℃), H(180℃)。
  • 絶縁電線に流すことができる最大の電流値を 許容電流 といい、抵抗器で定められた最大電力を 許容電力 という。
  • 抵抗器の許容電流の公式：I = √(P / R) [A]。

4. 電気回路の安全（p.54〜55）

  • 過電流を遮断して回路を保護する器具には ヒューズ と 配線用遮断器 がある。
  • ヒューズには 抵抗率が小さく融点の低い 金属が使われ、配線用遮断器には熱膨張率の異なる2枚の金属板を貼り合わせた バイメタル が使われる。
  • プラグとコンセントなどの接触状態によって生じる抵抗を 接触抵抗 といい、酸化被膜や汚れで大きくなると火災等の原因になる。
  • 絶縁抵抗の公式：V / I₀ [Ω]（絶縁抵抗計の単位表示は MΩ）。
  • 感電防止のため機器の金属部分を大地につなぐことを 接地（アース） といい、接地抵抗は V_EP / I [Ω] で求める。

5. 熱と電気（p.56〜57）

  • 2種類の金属の両端を接合した 熱電対 の2つの接合点に温度差を与えると起電力が生じる現象を ゼーベック効果 という。
  • ゼーベック効果で生じる起電力を 熱起電力、流れる電流を 熱電流、温度が高い方を 温接点、低い方を 冷接点 という。
  • 接合点を切り離して別の金属 C を挿入しても、両端の温度が同じなら熱起電力が変わらない性質を 中間金属の法則 という。
  • 熱電温度計に使われる コンスタンタン は、銅とニッケル の合金である。
  • 異なる金属の接合部に電流を流すと熱の発生・吸収が起こる現象を ペルチェ効果 といい、電子冷却装置（ペルチェ素子） に利用される。
  • 温度差がある単一導体に電流を流すとジュール熱以外の発熱・吸熱が起こる現象を トムソン効果 という。
  • 高温部から低温部へ電流を流すと、銅・アンチモン は熱を発生し、鉄・ニッケル は熱を吸収する。なお 鉛 はトムソン効果が起こらない基準金属である。
